# Benmoose Tap

## How do I install these formulae?

`brew install benmoose/tap/<formula>`

Or `brew tap benmoose/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "benmoose/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
